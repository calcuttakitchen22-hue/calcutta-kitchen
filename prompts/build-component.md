# Build Component Prompt

Read the following documents before making any changes:

- CODEX.md
- vision.md
- sitemap.md
- design-system.md
- tech-architecture.md

## Task

Implement ONLY the requested component.

Requirements

- Follow the Design System.
- Follow the project architecture.
- Reuse existing components whenever possible.
- Do not duplicate logic.
- Keep the component reusable.
- Accept props instead of hardcoded values.
- Support mobile, tablet and desktop.
- Meet WCAG AA accessibility.
- Avoid unnecessary JavaScript.
- Use Astro best practices.
- Use semantic HTML.

Before writing code:

1. Explain your implementation plan.
2. Identify files that will be modified.
3. Mention any reusable components.

After implementation:

- Explain what changed.
- Mention any future improvements.
- Confirm the project still builds successfully.
