# Calcutta Kitchen Project Rules

## Purpose

These rules are mandatory for every contributor, whether human or AI.

They override convenience and personal preference.

---

# Rule 1

Calcutta Kitchen is a recipe discovery platform.

It must never evolve into a chronological blog.

---

# Rule 2

Recipe discovery is the highest priority.

Every page should help users find another recipe.

---

# Rule 3

Content is the hero.

The UI should support the recipes, not compete with them.

---

# Rule 4

Never duplicate components.

Reuse first.

---

# Rule 5

Never hardcode recipe information inside UI components.

Recipes always come from Content Collections.

---

# Rule 6

Every feature must improve at least one of:

- UX
- Performance
- Accessibility
- SEO
- Maintainability

---

# Rule 7

Every page must support mobile before desktop.

---

# Rule 8

Performance is a feature.

Never add JavaScript unless necessary.

---

# Rule 9

Every image requires:

- alt text
- optimization
- responsive sizing

---

# Rule 10

Before adding a dependency ask:

Can Astro already do this?

If yes, don't install anything.

---

# Rule 11

Every page should encourage users to continue exploring.

Dead ends are not allowed.

---

# Rule 12

The website should feel premium through simplicity, not decoration.

Whitespace beats visual clutter.

Large food photography beats heavy UI.
